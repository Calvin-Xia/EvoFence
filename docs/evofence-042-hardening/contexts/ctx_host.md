# 宿主适配域（ctx_host）

负责 5 个 agent 宿主的 plugin 与 extension 入口、三处路由入口（两个 marketplace 与项目级 pi 入口）、这些入口对 CLI 命令面与 flag 面的覆盖契约，以及集成守卫的三轴断言；不负责 CLI 命令本身的实现（归命令面域），不负责配置校验（归配置契约域）

## 术语表

- **覆盖**: 目录清单里的某条命令或 flag 被至少一个宿主集成的说明或工具实际引用；与闭包相反，闭包只要求集成提到的东西必须存在。Avoid: 命中率, 使用率
- **路由入口**: 只承载安装与发现路径、不承载能力的清单文件，即两个 marketplace 与项目级 pi 入口
