# 配置契约域（ctx_config）

负责四类 .evofence YAML 文档的 schema、字段装配、校验与加载，配置面文档的单一真相，以及能力键的定性与值域校验；不负责能力判定在运行期的执行（由能力判定函数与迭代主循环承担），不负责宿主侧可声明面（归宿主适配域）

## 术语表

- **能力键**: capabilities 下按能力名索引的条目，取值形态决定该能力是否被允许；开放 map 指键名不预先穷举。Avoid: 配置开关, 权限字段
- **死键**: 在合同模板中出现却没有判定消费的键；本轮处置为从模板删除，其中两个 acceptance 键因闭合对象兼容性而保留为无判定消费的空操作。Avoid: 无效配置, 废弃字段
