# 0005 — 三个新功能按非破坏方式实现并停在 0.4.2

本轮新增的横切报告格式选项、预检可执行修复、预算外推视图三项均为增量面：新 flag 或新命令进目录清单，既有默认输出与退出码契约不变，默认行为严格只读或逐字不变。因此三项与既有改动一同停在 0.4.2，不升大版本。

**Status：** accepted

**Context：** 三项都在既有判断之上加一层输出或执行，不改变任何既有判定。报告不带格式选项时输出与 0.4.1 逐字一致；预检不带修复选项时行为逐字一致且仍不创建运行目录、worktree 或账本事件；预算外推为增量段且数值对同一账本确定。

**Considered Options：** A 把三项拆到 0.5.0，版本语义更保守但把非破坏增量与破坏性变更混为一谈；B 三项按非破坏实现并与配置面纠偏一同停在 0.4.2，选中；C 把三项做成默认行为变更，会破坏既有输出契约。

**Why：** 0.4.1 已经以补丁版本加了两个新能力，本仓库的既有实践就是非破坏增量停在补丁版本。判据是行为可观察的默认路径是否改变，而不是是否新增了 flag。

**Consequences：** 变更日志需把三项写明为非破坏新增，并逐项声明既有默认输出不变。代价是功能与纠偏混在同一个补丁版本里，审查时需靠变更日志的分类来区分；若将来某项无法保持非破坏，须单独立 ADR 并改版本终点。
