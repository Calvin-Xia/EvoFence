# 执行编排域（ctx_exec）

负责执行编排：候选变更的运行调度、适配器接入、子进程管理、git worktree 隔离与预算记账；不负责门禁判定逻辑（经 ctx_gate 判定入口调用）、账本写入（运行记录交 ctx_ledger 落链）、配置格式定义（配置由 ctx_io 解析后传入）与集成适配细节（接入面属 ctx_ext）。

## 术语表

- **worktree 隔离**: 并行候选变更各自在独立 git worktree 检出中运行的隔离约定，主检出不被执行 agent 直接写入；这是进程级隔离约定，不是 OS 沙箱。Avoid: 沙箱、OS 级隔离
- **预算记账**: 对一次运行累计 token、费用与墙钟时间的记账，超限按不通过处理。Avoid: 估算、宽松计费
- **候选变更**: 待验证的一组改动，在独立 worktree 中执行并接受门禁判定与账本记录
