# 0005 — 任务完成、评价、晋升与激活分离

建议 TaskVerdict 不要求数值改善；Candidate/EvaluationReceipt 决定长期资格；Promotion 按预授权策略；Activation 由宿主安全点和回执确认。

**Status：** proposed（待裁决）

**Context：** 当前分数 min_delta 驱动 Git generation 接受；用户需要普通任务实用性与策略/经验/技能/工具演化。

**Considered Options：** 继续单一 acceptance 流程简单但混淆工作完成与学习收益；分层状态更复杂却能撤销并适配不同产物。

**Why：** 解决普通修 bug 完成也应成立、临时策略不应自动永久化的问题。

**Consequences：** 多种 DecisionRecord 与资产状态，必须唯一生产判定入口与强绑定 receipts。
