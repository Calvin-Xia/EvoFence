# 0009 — 轻量协议内核与可选基础设施

建议 TypeScript 单仓分离 protocol/kernel/runtime/host/storage/surface，ports 显式注入；core 不强依赖 Git、CLI、SQLite、SP。SP 为可选规划转换。

**Status：** accepted

**Context：** 现有 root exports 导入 native ledger；单一 CLI 流程强绑定本地文件和品牌。

**Considered Options：** 拆很多 npm 包治理成本大；单入口易带来 native依赖；模块/exports 隔离先行可延后独立发包。

**Why：** 保证宿主嵌入简单、职责清楚，避免为图景引入不必要基础设施。

**Consequences：** 共享 schema 与依赖方向需约束；bridge 转换损失显式；云端/多机器分布式暂不承诺。
